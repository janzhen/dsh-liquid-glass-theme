# dsh-liquid-glass-theme

DSH Web 界面的液态玻璃皮肤：极光渐变背景 + 半透明玻璃表面，亮/暗双配色。

## 特性

- **全量 `--dsw-*` 令牌重映射**（21 个 × 亮/暗），纯标准 CSS，零哈希选择器
- **浮动输入框与交互卡片磨砂玻璃（`backdrop-filter`）**：为 `[data-composer-card]` 及交互浮层注入轻度高斯模糊（6px blur + 180% saturation），历史内容穿过输入框下方时被柔和虚化，消除字迹锐利重叠的同时保留极高的半透明通透与光影流动感
- **全屏右侧边栏（最大化）整屏磨砂**：右栏的 `fullscreen` 呈现是铺满视口（`position:fixed;inset:0;z-index:40`）并沿用 `bg-base` 的面板，而 `bg-base` 的 alpha 是按「框架 + 会话根」两层消费校准的 —— 这第三层大面积消费者压住的是**正文**，底下字迹会直接叠上来。只对该面板注入 `blur(16px) saturate(150%)`：全局通透度不动，被盖住的内容被虚化到不可读（`body [data-sidebar-right-panel="fullscreen"]` 用 (0,1,1) 压过产物的 `.class` 规则，不依赖样式表注入顺序；`data-sidebar-right-panel` 是稳定产品钩子而非哈希类名）
- **改动文件 diff 悬停浮层磨砂**：改动文件卡片（turn tail）悬停某一行时弹出的对比浮层，是 `bg-layer-1` 的一张纸（亮 0.55 / 暗 0.40），而它浮在**这一轮对话的正文之上** —— 这个令牌是按「站在内容后面的面板」校准的，于是 diff 行和底下的正文字迹直接互相穿插，两层字叠着没法读。修法与全屏侧边栏同源：只虚化背景，令牌不动。12px 是实测曲线的拐点（真实 Chromium、极光 seed 7、亮暗双色、`tools/preview-glass.mjs`）：被盖住内容在卡片内的**最坏透出**从亮 2.84:1 / 暗 5.78:1 掉到 1.16 / 1.32，而卡片背后极光的**大尺度变化**仍保留「无卡片」时的 51% / 71% 振幅（= 没有变成不透明的板子）；6px 还会把正文留成看得出笔画的糊影（1.35 / 1.75），20px 只多买 0.04（亮）/ 0.08（暗）的抑制、却要再让出 4 个点的极光。浮层自己的 diff 正文一点没动（最弱行类亮 3.1 / 暗 6.1，前后一致），因为 `backdrop-filter` 只画元素背后的东西。钩子用预览根上的稳定属性 `data-changes-hover-preview`，靠 `:has()` 反向选中原件 portal 到 `document.body` 的那张卡（那张卡的类名是构建哈希，产物自己的样式表也用这个写法：`:has(> [data-code-block-banner])`）；`body >` 前缀把规则钉死在 portal 出来的那张卡上 —— 光写 `:has()` 会连 `body` 一起匹配，等于把整个应用糊掉
- **极光背景**：`body` 渐变底 + `body::before` 固定光斑层，内容滚动时光斑不动
- **极光几何与色相每次加载重掷**：几何收敛到**一个旋钮** `TRAVEL`（0–1）—— 每个光斑在作色锚点 `at` 周围、按「满行程 `reach` × TRAVEL」取随机数，半径与淡出停点也按 TRAVEL 收缩（`TRAVEL = 0` 几何完全钉死、只剩色相变化，`= 1` 为满行程）。色相走**整体相干旋转**：`PALETTE_HUE` 一次滚出 ±30° 加到全部光斑，`BLOB_HUE` 再给每斑 ±7° 偏移，饱和度与亮度取自作色值、不参与旋转，alpha 与叠放顺序固定。亮暗共用同一次掷点，切主题不会重新洗牌。当前 `TRAVEL = 0.35`，实测相邻两次加载的逐点覆盖差 0.052（满行程 0.099、只换色 0）、光团质心位移 4.9% 视口（满行程 10.1%）、画面平均覆盖 0.066–0.110、死区 42%–67%（满行程为 0.030–0.128 与 29%–81%）—— 比满行程明显收敛，同时保住"色块真的会走位"。色相带宽由配色识别度而非对比度决定：配对实测（同几何、色相开/关，200 次构建）旋转对正文对比度平均中性（亮 100.7%、暗 98.2%，任何一层表面栈的位移都在 2.3% 以内），当前 ±30° 下最弱会话栈仍有暗 7.57 / 亮 11.06，离 WCAG AA 的 4.5 底线很远 —— 所以带宽是留给识别度的额度。限制它的是绿色：再宽一转，557.7 nm 的绿就滑向黄绿或青绿、630.0 nm 的红开始偏橙，越出这几条谱线所属的色域。只在"构建样式表"时掷一次，页面加载期间数值冻结 —— 没有任何动画
- **极光配色按真实谱线重写（是换证据，不是调色）**：六个光斑本来就是极光的高度分层，现在色相由谱线决定而不是审美 —— 原子氧绿线 557.7 nm（100–200 km，最强辐射，占左侧重块、底部带与核心三行）、同一原子的红线 630.0/636.4 nm（要 ≥200 km 的稀薄高空才发得出来，落在两个上角）、N₂⁺ 第一负带 427.8 nm（电子能量高、位置低时帷幕下缘的蓝，占右侧重块）、以及 100 km 以下氧线被碰撞淬灭后只剩的氮即时辐射（右上与蓝相接的玫红边缘）。**权重同样跟着证据走**：绿行拿表里最高的 alpha（暗 0.70 / 0.58 / 0.40），红与玫红最低（0.40 / 0.36）—— 真实极光是绿帷幕加一层淡淡的红晕，而一块和互补的品红均分面积的柔光斑只会混成橄榄色，这是第一版试色时实测到的（绿压在品红上 → 灰橄榄，改权重后同一位置重新饱和）。色相也不是照抄波长：屏幕再现单色谱线时会被叠在下面的层去饱和，所以作色的帷幕绿比 557.7 nm 的色相（~101°）高一点（118°，核心 104°），保证谱线本身仍落在 ±30° 的掷点范围内。亮色整份压淡（S 46–52 对暗色 62–66）：白昼极光本来就淡，同时避免亮色变成一整片绿野。亮度是唯一的对比度旋钮、alpha 不是 —— 绿色在亮度上是最亮的色相，于是它被压到比被它替换的紫低 32 个点，而不是把这行调淡；结果整份配色反而比原来更安全（最弱会话栈暗 7.57 / 亮 11.06，改前 5.39 / 10.50；单纸 5.54 / 8.96，改前 3.61 / 8.26）。几何、`TRAVEL`、叠放顺序与掷点机制一律未动，覆盖 0.294 / 0.321、死区 0–3%，与改前 0.301 / 0.324 一致，确认这次只动了颜色与各行权重。取舍讲清楚：这是"一眼认得出是极光"的取向 —— 暗色从靛紫变成绿帷幕配红晕，亮色从冷调玻璃变成偏薄荷/淡玫的粉彩，不再中性。以上数字与配图的复现命令见「复现测量」
- **Trajectory 视图按「页面」而非「卡片」重新锚定表面层级**：Trajectory 标签页是产物里表面层级最深的消费者 —— 框架与会话根已经各画一层 `bg-base`，其上的视图根、记录表容器、记录表又各画一层 `bg-layer-1`。令牌是按「单张纸」而不是「整摞纸」校准的，五层叠起来覆盖率达到亮 96% / 暗 88%，极光只剩 3.9% / 11.8%（聊天区是 42.3% / 54.8%）—— 这就是那里看着跟没装主题一样的原因。修法不是逐层去压，而是在视图内重新锚定层级：视图根不再画纸（它本身就是内容区，和聊天消息列表一样），并把该子树里的 `bg-layer-1` 降到页面档。记录表于是只剩两层纸压在两层底之上，极光落到聊天区的三分之二（200 次构建：极光贡献量 mean ΔRGB 亮 4.7 / 暗 9.3，聊天区 7.0 / 13.9，改前 0.6 / 3.0），正文最差对比度仍远在 4.5 之上（最差一次构建亮 12.7 / 暗 8.7，改前那摞近乎不透明的纸是 16.7 / 12.8 —— 主题为根本用不到的对比度付了钱）。嵌套详情面板仍读得出层次（3.8 / 7.6 ΔRGB），行悬停与选中的半透明产物色照旧。`data-conversation-composer-overlay` 是产物为「请求浮层 composer」设的稳定钩子，只有 Trajectory 一个视图设置它（已跨全部已挂载客户端包核对过）；`body` 前缀 (0,1,1) 稳压视图自己的 `.class` (0,1,0)，与样式表注入顺序无关。副作用：轮次竖线与激活轮次标签的色值由 `color-mix(蓝 22%, bg-layer-1)` 得到，层级变薄后它们跟着变淡（亮 49.4 → 43.8 ΔRGB，保留 89%；暗保留 98%），仍在清晰可见的范围
- **Trajectory 的时间概览带同样降一档，但不成洞**：Overview 是视图里唯一的嵌套面，画布用的是 `bg-layer-2`（同一个令牌还被工具栏搜索框和记录类型气泡消费）。它按同一条规则再降一级 —— 落到记录表极光可见度的三分之二（透过率 19.0% / 24.7%，记录表是 28.4% / 36.8%），也就是在记录表之上再加 33% 覆盖，仍然读得出「一条带子」。带上时间条对 3:1 的图形对比度是 4.14 / 5.27
- **气泡必须只钉那一个（踩过坑）**：这个视图里的气泡来自共享 tooltip 原件 —— 原件画的是**深色气泡 + 白色文字**（`bg-tooltip-bg`），只有**记录类型**那一个气泡被视图自己换了面（`.kindSlot [role=tooltip]` 把它换成 `bg-layer-2` + `panel` 阴影 + `label-primary` 文字）。所以 `bg-layer-2` 降档后要钉回浮层档时，作用域必须收窄到那一个气泡：用 kind 标签上的稳定钩子 `[data-role-kind]`。只写 `[role=tooltip]` 会把浅色背景压到原件的白色文字底下 —— 亮色下白字对比度掉到 **1.02:1**（等于隐形），时间条与「加载更早」两个 tooltip 全部读不出来，这是已经发生并修掉的一次回归。收窄后原件气泡维持深色（白字对比 13.94 / 9.59），被换面的那个是 16.47 / 14.74，且仍遮挡 93.8% / 94.5% 的底下行
- 亮暗自动切换（主题展示器的 `body[data-ds-dark-theme]` 稳定属性）
- `bg-base` 的透明度按嵌套消费的复利校准（框架 + 会话根双层的组合透过率）

## 安装

```sh
dsh plugin --profile web add link:<本目录>
```

安装命令会自动把插件行加进 profile 的 bundle 栈，重启 profile 生效。

## 结构

```
package.json             # dsh.client 声明（./client 出口）
cordis.patch.yml         # bundle patch：insert 一条插件行
lib/index.js             # 宿主半（空 apply，仅为加载器占位）
lib/client.js            # 浏览器半：令牌表 + 极光 + 玻璃表面 + diff 浮层 + Trajectory 表面处理，ctx.effect 生命周期挂载
tools/aurora.mjs         # 极光测量/渲染工具：加载真实 client 模块 → 求值产出的 CSS → 合成真实表面栈 → 对比度/覆盖数字 + PNG
tools/preview-glass.mjs  # diff 悬停浮层工具：真实 Chromium 里挂真实产物样式 + 真实 DOM → 透出/对比度/通透度数字 + 对照 PNG
```

## 复现测量

所有对比度、覆盖与配图都由 `tools/aurora.mjs` 产出，它不重写样式逻辑，而是把 `lib/client.js` 当作真实模块加载（假 `window.__ModuleLoader__` + 假 `document`），捕获 `apply()` 装上的样式表后自己求值：`body` 渐变 → 六个径向光斑（按 CSS 的叠放顺序自下而上）→ 令牌表里的表面栈。`Math.random` 被换成定种 PRNG，所以两个文件在同一 `--seed` 下几何完全一致，差异只剩配色。

```sh
# 当前配色：每个表面栈的最差 / 平均对比度 + 覆盖与死区
node tools/aurora.mjs measure --builds=200

# 与旧配色配对对比（同一几何），并出一张对照图：行=亮/暗，列=旧/新
git show main:lib/client.js > /tmp/old-client.js
node tools/aurora.mjs measure --file=/tmp/old-client.js --builds=200
node tools/aurora.mjs compare --old=/tmp/old-client.js --file=lib/client.js --seed=42
```

表面栈按令牌消费方命名：`单纸 base×1` 在产物里不出现（`bg-base` 只被框架与会话根两层消费），列出来是诊断用；真正的地板是 `会话栈 base×2`。

`backdrop-filter` 是合成器特性，算不出来，所以浮层那一项由 `tools/preview-glass.mjs` 在**真实无头 Chromium** 里量：它照样加载真实 client 模块取极光，同时把产物自己的样式表拼进来（静态 web CSS 里带着 HoverCard 的 `.preview` 规则，产物 bundle 里内联着 ChangedFiles/FileDiff 的模块 CSS），再按原件的算术摆好 portal 到 `document.body` 的那张卡 —— 24px 侧内缩、8px 锚点间距、420px 上限。每个状态截五张（原文 / 隐藏底字 / 隐藏 diff 字 / 两者都隐藏 / 无卡片），差值给出「透出」与「diff 自身对比度」，块均值给出极光还剩多少。

```sh
# 前后对照：列 = none（无规则）/ shipped（当前模块自己的 preview 表）
node tools/preview-glass.mjs --seed=7

# 选半径用的扫描：`--states` 会去掉模块自带的那张表，改用给它的声明
node tools/preview-glass.mjs --states="none|backdrop-filter:blur(6px) saturate(180%)|backdrop-filter:blur(12px) saturate(160%)|backdrop-filter:blur(20px) saturate(150%)"
```

工具默认从 `DSH_PROFILE_DIR`（或 `$DSH_HOME/profiles/$DSH_PROFILE`）里解析产物包，所以量的是**正在跑的那一份**产物；Chromium 走 `$CHROME_PATH`，默认取 ms-playwright 缓存里的 headless shell。
